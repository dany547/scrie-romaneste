# Text pentru social media și blog personal

Alege fișierul după gen. Regulile generale de limbă (`../limba/anti-tipare-ai.md`, în special §I, §J, §K)
se aplică integral; aici sunt doar constrângerile de gen.

| Ce scrii | Fișier |
|---|---|
| postare organică: Instagram, Facebook, LinkedIn, TikTok, forum | `organic.md` |
| blog personal, lifestyle, jurnal public (nu articol SEO) | `blog-personal.md` |
| reclamă plătită (Google, Meta, TikTok) | `../reclame/platforme.md`, `../reclame/voce.md` |
| articol de blog cu intenție de căutare | `../seo/blog-keyword.md`, `../seo/flux-articol.md` |

Regula de lucru: **limite numerice doar cu sursă oficială și dată**. Ce nu e confirmat se scrie
„neverificat" și se verifică în interfața platformei înainte de producție. Sfaturile de conversie sunt
sfaturi, nu reguli.
